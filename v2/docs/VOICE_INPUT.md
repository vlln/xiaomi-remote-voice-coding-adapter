# 配合语音输入法使用

Xiaomi Remote 负责把遥控器麦克风变成虚拟麦克风，并把语音键映射成一个普通键盘键。
Typeless、豆包语音输入法这类工具负责“听到快捷键后拾音，再把语音转成文字”。

两边使用**同一个按键**，就能用遥控器直接输入文字。

## 工作原理

```text
按住遥控器语音键
  ├─ BLE ATVV → Xiaomi Remote → BlackHole 2ch（虚拟麦克风）
  └─ 语音键目标键（例如 F6）
        └─ Typeless / 豆包语音输入法的“按住说话”快捷键
              └─ 读取 BlackHole 2ch → 转文字 → 输入到当前焦点
```

## 推荐配置

| 设置项 | 建议值 |
|---|---|
| 遥控器语音键目标 | **F6**（或一个不冲突的功能键） |
| Xiaomi Remote 音频输出 | **BlackHole 2ch** |
| 输入法的麦克风 | **BlackHole 2ch**（若没有独立选项，把系统输入设为它） |
| 输入法快捷键模式 | **按住说话 / Push-to-talk** |
| 输入法快捷键 | 与遥控器语音目标相同，例如 **F6** |

> 不建议把语音目标设成右 Option 这类纯修饰键：部分输入法的快捷键输入框不接受“只按修饰键”。F6 这类普通键更稳。
>
> 如果 F6 在 macOS 上被系统当作媒体键，可以改用 F7/F8 等不冲突的键，或按 Fn+F6。

## Typeless

1. 在 Typeless 的设置里找到「快捷键 / 听写快捷键」。
2. 选择「按住说话」模式。
3. 把快捷键设为与遥控器语音目标相同的键（例如 F6）。
4. 把 Typeless 的麦克风设为 **BlackHole 2ch**。
5. 光标放在输入框里，按住遥控器语音键说话，松开后等待文字上屏。

Typeless 设置说明：<https://www.typeless.com/help/quickstart/settings>

## 豆包语音输入法

1. 打开豆包语音输入法的设置，找到「语音输入快捷键」。
2. 选择「按住说话」模式。
3. 设为与遥控器语音目标相同的键（例如 F6）。
4. 把输入法的麦克风设为 **BlackHole 2ch**。
5. 光标放在输入框里，按住遥控器语音键说话，松开后等待文字上屏。

不同版本的菜单名称可能略有差异，认准「语音输入 / 听写 / 快捷键」即可。

## 两个输入法同时装

- 两个工具都把 F6 当全局快捷键时会冲突，按下会同时触发或互相抢占。
- 同一时间只给一个输入法启用语音快捷键；另一个先关闭。
- 如果都要保留，可以给它们设置不同的目标键，并在 Xiaomi Remote 里切换语音目标。

## 常见问题

### 按遥控器没反应

1. 确认 Xiaomi Remote 显示 **已连接**，快速设置 3/3。
2. 在「按键映射」点语音键，把目标键设为 F6，确认右侧显示 F6。
3. 用「测试按键」确认按语音键会显示 `语音键 → F6`；测试模式会拦截真实按键，测试完先停止。
4. 确认输入法处于「按住说话」模式，且快捷键确实是 F6。

### 有文字但没声音/识别不到

- 输入法麦克风没有选 BlackHole 2ch，仍在用内置麦克风。
- 或者 Xiaomi Remote 的音频输出不是 BlackHole 2ch。
- 确认会议 App/输入法读取的是同一个虚拟设备。

### 按住后只触发一下

- 输入法可能设置成了「按一下开始、再按一下结束」而不是「按住说话」。
- 改成按住模式；否则遥控器松键后音频桥接停止，输入法还在等下一段音频。

### 两个输入法冲突

- 只保留一个输入法的语音快捷键；或给它们分配不同按键。
